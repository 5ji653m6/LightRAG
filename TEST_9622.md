## Features to Test

### 1. Auto-Rotate Feature 🔄

**URL**: http://localhost:9622/graph3d/viewer

**What to expect**:
- Galaxy should be **slowly rotating automatically** when you open the page
- Gentle, continuous rotation (speed: 0.45)
- Smooth damping effect

**Controls**:
- Click "🔄 Auto Rotate" button to toggle on/off
- Button appears fully opaque when ON
- Button dims to 50% when OFF
- Query Log shows: "🔄 Auto-rotate enabled" or "⏸️ Auto-rotate disabled"

**Manual Interaction**:
- You can still drag to rotate manually
- Galaxy continues auto-rotating after you release

### 2. Real-Time Query Activation 🌐

**Test Query**:
```bash
curl -X POST http://localhost:9622/query/data \
  -H "Content-Type: application/json" \
  -d '{"query": "testosterone", "mode": "hybrid", "top_k": 20}'
```

**What to expect in the viewer**:
1. Query Log shows: `🌐 External query: "testosterone"`
2. Query Log shows: `✅ Found X entities`
3. Entity list appears in log
4. Query Log shows: `⚡ Activated X neurons`
5. **Neurons light up bright white** in the galaxy
6. **Edges between activated entities glow white**
7. Activation persists until next query

**Test Different Queries**:
```bash
# Query 1
curl -X POST http://localhost:9622/query/data \
  -H "Content-Type: application/json" \
  -d '{"query": "diabetes treatment", "mode": "hybrid", "top_k": 15}'

# Query 2
curl -X POST http://localhost:9622/query/data \
  -H "Content-Type: application/json" \
  -d '{"query": "protein synthesis", "mode": "hybrid", "top_k": 15}'
```

Each query will:
- Clear previous activation
- Activate new neurons
- Show in Query Log with 🌐 marker

### 3. Manual Query (from viewer) 📝

**In the viewer**:
1. Enter query in input box (bottom-left)
2. Press Enter or click "Query"
3. Watch neurons activate

**Query Log shows**:
- `🔍 Querying: "your query"` (manual query marker)
- `✅ Found X entities`
- `⚡ Activated X neurons`

**Difference**:
- Manual queries: `🔍` icon
- External queries: `🌐` icon

## Troubleshooting

### Auto-rotate not working?
- Check browser console (F12) for errors
- Verify button shows "🔄 Auto Rotate"
- Try clicking the button to toggle

### Real-time activation not working?
- Check Query Log panel (bottom-right)
- Verify server is responding: `curl http://localhost:9622/health`
- Check activations endpoint: `curl http://localhost:9622/query/activations`
- Check browser console for polling errors

### Neurons not lighting up?
- Wait 2-3 seconds after query (polling interval)
- Check if entities exist in visualization
- Try demo activation button first
